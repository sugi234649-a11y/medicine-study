# 薬52種：介護士の学習ノート

`dist/index.html` をブラウザで開くと動作します。ビルドや外部ライブラリのダウンロードは不要です。既存のゲームには変更を加えていません。

## 初版の内容

- 指示書の52項目、15分類。データは `dist/data.js` に分離。
- 一覧、一般名・商品名・作用・観察ポイントの検索、分類と観察の絞り込み。
- 分類・作用・観察クイズ（2択・4択）、ヒント、暗記カードの自己評価。
- 苦手の再出題、正解回数に応じた翌日・3・7・14・30日後の復習。
- 学習記録、ダークモード、名前の表示切り替え。
- Web Audioによる正解・不正解・完了の短い効果音、音量、ミュート。初期状態は音オフ。
- 薬名の読み上げ（端末が日本語音声合成に対応する場合）。

## スマートフォンで使う

このフォルダの `dist` の中身を静的Webホスティングにアップロードすれば、HTTPSのURLをSafari・Chromeで開けます。現時点では公開用Sitesツールが接続されていないため、外部公開URLは発行していません。ローカルファイルのリンクは、このPCでの確認用です。

学習記録はlocalStorageに保存し、サーバーには送信しません。端末・ブラウザ・URLのオリジンごとに独立します。PCからスマホへの記録移行や複数端末同期は未実装です。ブラウザのデータ削除で消えることがあります。ファイルでの保存動作はブラウザ依存のため、継続利用にはHTTP(S)配信を推奨します。

## 教材の扱い

臨床判断・投薬判断用ではありません。提供された教材とPMDAの一部の重要安全情報をもとにした初学者向け要約で、全項目の医療職監修は未実施です。施設での正式な研修には専門職の確認が必要です。資料へのリンクはアプリの医療安全画面に掲載しています。

## 検証

`node --test tests/logic.test.cjs`

スマホ実機での音量・サイレントモード・読み上げ音声は端末設定にも依存します。

Chromeの自動操作で、320px・390px・1440px幅、200%文字サイズ、検索、3種類のクイズ、ヒント、再出題、暗記カード、保存復元、音のオン・オフによる音声生成を確認済みです。スクリーンショットは `test-output` に保存しています。Safari/WebKitとスマホ実機は未確認です。音声生成の確認は自動検証であり、実機スピーカーでの聴取確認ではありません。
